0. 全体像と重要度

線形代数Iは「ベクトルの空間」と「行列による計算」を、連立一次方程式と行列式へつなげる授業です。

最重要

定義を使って判定し、手を動かして計算できる必要がある内容です。

  • 部分空間の判定
  • 一次独立・一次従属
  • 基底・次元
  • 行基本変形、階数
  • 連立一次方程式の解法

重要

計算や証明を支える道具です。最重要テーマを理解するために必要です。

  • 数ベクトルの演算
  • 行列の和・積・転置
  • 正則行列と逆行列
  • 基本行列
  • 2次・3次の行列式

補足

理解の見通しをよくする内容です。余裕があれば図や意味まで押さえると強いです。

  • 体 K, R, C の違い
  • ブロック行列
  • 行列式の幾何学的意味
  • 解空間の次元
この授業の主役は、抽象的な空間の考え方と、行列を使う具体的な計算です。

0.5 新出定義まとめ

講義資料で新しく出てくる定義を、使いどころと一緒にまとめます。定義は暗記ではなく、問題を解くための道具として読むのが大切です。

体 K

足し算・引き算・掛け算・0でない数での割り算ができる数の世界。講義では主に R や C を考えます。

数ベクトル

数を縦または横に並べたもの。縦に並べると列ベクトル、横に並べると行ベクトルです。

部分空間

足しても、スカラー倍しても、同じ集合の中に残る集合。レポート1の中心テーマです。

一次結合

c1v1 + c2v2 + ... + ckvk の形。生成、一次独立、基底のすべてにつながります。

生成する

与えられたベクトルの一次結合で、目的の空間全体を作れること。復習1の基底判定で使います。

一次独立

一次結合で0を作る方法が、全係数0しかないこと。無駄なベクトルがないという意味です。

基底

一次独立で、かつ空間を生成するベクトルの組。座標を作るためのものさしです。

次元

基底に含まれるベクトルの本数。空間に必要な独立方向の数です。

正則行列

逆行列を持つ正方行列。掃き出しで単位行列にできるか、行列式が0でないかで判定します。

階数 rank

行階段形にしたときの0でない行の本数。連立方程式の解の有無、自由変数、逆行列の有無に直結します。

拡大係数行列

連立方程式の係数と右辺を横に並べたもの。[A | b] と書きます。

行列式 det

正方行列に対応する数。2次元では面積倍率、3次元では体積倍率を表します。

置換と符号

数字の並べ替えと、その並べ替えが偶数回の交換か奇数回の交換かを表す考え方。復習5のテーマです。

冪零行列

何回か掛けると零行列になる行列。レポート3のように、(I + A)^n の計算を大幅に短くできます。

定義を問われたときの答案の作り方

定義問題は「言葉を知っているか」だけでなく、「その定義を使って判定できるか」を見られます。例えば部分空間なら、零ベクトル、和、スカラー倍を確認します。一次独立なら、係数を置いて0になる条件を解きます。

1. 数ベクトルと演算

講義資料 §1-1, §1-2。線形代数の最小単位は「数を縦に並べたもの」です。

用語説明

用語意味
スカラーベクトルを何倍するかを表す普通の数。資料では K = Q, R, C などを使う。
数ベクトル(a1, a2, ..., an) のように、数を並べたもの。縦ベクトルと横ベクトルがある。
零ベクトルすべての成分が 0 のベクトル。記号は 0。
標準ベクトルe1, e2, ..., en。1つの成分だけが1で、他は0のベクトル。
重要: ベクトルの和とスカラー倍
成分ごとに足す、成分ごとに同じ数を掛ける。以後の全計算の基本です。
補足: K 上のベクトル空間
R 上なら実数倍、C 上なら複素数倍まで許す、という意味です。

基本計算

a = a1a2...an , b = b1b2...bn
a + b = a1 + b1a2 + b2...an + bn
c a = c a1c a2...c an
縦に並べたものを「列ベクトル」と呼びます。成分ごとに同じ操作をします。

縦ベクトルか横ベクトルかを混ぜないことが大切です。講義資料では縦ベクトルを中心に扱います。

直感

ベクトルは「矢印」と見ると分かりやすいです。和は矢印をつなぐこと、スカラー倍は矢印を伸ばす・縮める・反対向きにすることです。

一般形を小さい数で確認する

一般形は、いきなり見ると記号の列に見えます。まず n = 3 で試します。

a = 123 , b = -104
a + b = 027
2a = 246

本質は「各成分が独立に計算される」ことです。ベクトル全体を一度に理解しようとせず、1成分ずつ同じ操作が走っていると見ます。

添字の読み方

a1, a2, ..., an は「a が n 個ある」のではなく、「a の1番目、2番目、..., n番目の成分」という意味です。見た目が紛らわしいときは、頭の中で a_1, a_2, ..., a_n と読んでください。

a = 5-20
このとき a_1 = 5, a_2 = -2, a_3 = 0 です。

T のような初見記号

参考書では [1, 2, 3]^T のような表記がよく出ます。右上の T は transpose の略で、「横に書いた行ベクトルを縦に並べ替える」という意味です。

[1, 2, 3]T = 123

このサイトでは、初学者が読みやすいように、できるだけ縦ベクトルは最初から縦に表示します。講義資料や試験問題で ^T が出たら「縦に直す記号」と読んでください。

高校数学からの違い

高校では2次元や3次元の矢印が中心ですが、線形代数では R^n のように何次元でも同じルールで扱います。4次元以上は絵にしにくいだけで、計算ルールは同じです。

2. ベクトル空間・部分空間

講義資料 §2-1。抽象度が上がる最初の山です。「足しても、何倍しても、集合から出ない」が合言葉です。

用語説明

用語意味
ベクトル空間ベクトルの和とスカラー倍ができ、その計算がいつもの法則を満たす集合。
部分空間大きなベクトル空間の中にある、小さなベクトル空間。
閉じている集合の中のものを計算しても、結果が集合の外へ出ないこと。
生成される空間いくつかのベクトルの一次結合で作れる全ベクトルの集合。記号は span(v1, ..., vk)。
最重要: 部分空間の判定
空でない集合 W が部分空間かどうかは、u, v in W なら u+v in W、c u in W が成り立つかで見る。
重要: 原点を通るか
部分空間なら必ず零ベクトルを含みます。図形でいえば、直線や平面は原点を通っている必要があります。
補足: 方程式で表された集合
Ax = 0 の解集合は部分空間。Ax = c で c != 0 なら一般には部分空間ではありません。

直感

部分空間は「原点を中心に、足す・伸ばすをしても壊れない世界」です。原点を通る直線は伸ばしても同じ直線上に残ります。

部分空間チェック

✓
零ベクトルが入っているか。
✓
任意の2つを足しても集合内に残るか。
✓
任意のスカラー倍をしても集合内に残るか。

実際の答案では、3つを別々に書くより「任意の a, b in K と u, v in W に対して a u + b v in W」を示す形がスマートです。

部分空間である集合

W = {(x, y) in R^2 | y = 2x} を考えます。これは原点を通る直線です。

(1, 2), (3, 6) in W (1, 2) + (3, 6) = (4, 8) も y = 2x を満たす 5(1, 2) = (5, 10) も y = 2x を満たす

足しても何倍しても条件 y = 2x が壊れないので、部分空間です。

部分空間ではない集合

U = {(x, y) in R^2 | y = 2x + 1} は、原点を通らない直線です。

(0, 1) in U 2(0, 1) = (0, 2) しかし (0, 2) は y = 2x + 1 を満たさない

「形が直線だから部分空間」ではありません。計算で集合の外へ出るなら、部分空間ではありません。

なぜ原点を含む必要があるのか

部分空間なら、任意のベクトル u に対して 0u も同じ集合に入る必要があります。ところが 0u は必ず零ベクトルです。

つまり、部分空間である限り、零ベクトルは自動的に含まれます。原点を通らない直線や平面が部分空間になれないのはこのためです。

狙われやすい点

  • 条件式に右辺の定数がある集合が部分空間かどうか。
  • Ax = 0 と Ax = b の違い。
  • 「零ベクトルを含む」だけで部分空間と判断するミス。足し算とスカラー倍でも閉じている必要があります。

3. 一次独立・一次従属

講義資料 §3-1。ベクトルの集まりに「無駄があるか」を調べるテーマです。

用語説明

用語意味
一次結合c1 v1 + c2 v2 + ... + ck vk の形。
一次独立c1 v1 + ... + ck vk = 0 の解が c1 = ... = ck = 0 だけ。
一次従属0でない係数を使って、ベクトルの一次結合を0にできる。
自明な解全部の係数が0である解。
最重要: 定義を方程式にする
c1 v1 + ... + ck vk = 0 を立て、係数 c1, ..., ck を未知数として解く。
重要: ベクトル数が次元より多いと従属
R^2 に3本以上、R^3 に4本以上のベクトルがあると、必ず一次従属です。

直感

一次独立は「どのベクトルも他のベクトルの組み合わせでは作れない」状態です。一次従属は「誰かが他のベクトルで再現できる」状態です。

答案の型

c1 v1 + ... + ck vk = 0 とおく。
成分ごとに方程式へ分解する。
連立方程式を解く。
解が全部0だけなら一次独立。0以外があれば一次従属。

一次従属の例

v1 = (1, 2), v2 = (2, 4) とします。

v2 = 2v1 つまり 2v1 - v2 = 0

0でない係数 2, -1 を使って0を作れたので一次従属です。見た目では「同じ方向のベクトルが重複している」と考えます。

一次独立の例

v1 = (1, 0), v2 = (1, 1) とします。

c1(1, 0) + c2(1, 1) = (0, 0) 成分で見ると c1 + c2 = 0 c2 = 0 よって c1 = 0, c2 = 0

0を作る方法が「両方0倍」しかないので一次独立です。2本が同じ直線上にないことが本質です。

一次独立の定義の意味

c1v1 + ... + ckvk = 0 を調べるのは、「ベクトル同士が打ち消し合って0を作れるか」を見るためです。

もし0でない係数で0を作れるなら、そのうち1本は他のベクトルの組み合わせで表せます。つまり、そのベクトルは新しい方向を増やしていません。

よくある勘違い

  • ベクトルに0成分が含まれるだけで一次従属だと思う。これは誤りです。
  • 2本のベクトルの長さが違うから一次独立だと思う。方向が同じなら長さが違っても従属です。
  • 答えだけ「一次独立」と書き、係数方程式を示さない。試験では根拠が必要です。

4. 基底・次元・座標

講義資料 §4-1。空間の中で「必要最小限のものさし」を作る章です。

用語説明

用語意味
生成するそのベクトルたちの一次結合で、空間内のすべてのベクトルを作れること。
基底一次独立で、かつ空間全体を生成するベクトルの組。
次元基底に含まれるベクトルの本数。
座標基底を使ってベクトルを表したときの係数。
最重要: 基底 = 一次独立 + 生成
片方だけでは足りません。独立だけなら空間全体を作れない可能性があり、生成だけなら無駄がある可能性があります。
重要: 次元は基底の本数
同じ空間なら、どの基底を選んでも本数は同じです。
補足: 多項式空間
資料では多項式の空間も扱います。例えば次数1以下の多項式は 1, x を基底にでき、次元は2です。

直感

基底は「その空間の座標軸」です。標準基底でなくても、空間全体を一意に表せるものさしなら基底になります。

よく出る例

空間基底の例次元
R^2e1=(1,0), e2=(0,1)2
R^3e1, e2, e33
原点を通る平面平面上の独立な2本2
次数1以下の多項式1, x2

標準基底でない基底

R^2 では (1, 0), (0, 1) だけが基底ではありません。例えば v1 = (1, 1), v2 = (1, -1) も基底です。

x = (3, 1) を v1, v2 で表す: a(1, 1) + b(1, -1) = (3, 1) a + b = 3 a - b = 1 よって a = 2, b = 1 (3, 1) = 2(1, 1) + 1(1, -1)

基底とは「空間の中の点を表すためのものさし」です。標準の x 軸・y 軸でなくても、2本が独立なら別の斜めの座標軸として使えます。

基底を判定するときの順番

  1. まず一次独立かを見る。無駄なベクトルがあるなら基底ではない。
  2. 次に空間全体を生成するかを見る。足りない方向があるなら基底ではない。
  3. R^n で n 本ある場合は、一次独立を示せば生成も従う。

なぜ基底が「ものさし」になるのか

基底が空間を生成するので、どんなベクトルも基底の一次結合で表せます。さらに基底が一次独立なので、その表し方は1通りに決まります。

「表せる」と「一意に表せる」がそろうため、基底の係数をそのベクトルの座標として使えます。

狙われやすい点

  • 与えられたベクトルの組が基底か判定する問題。
  • あるベクトルを指定された基底で座標表示する問題。
  • 基底の本数から次元を答える問題。

5. 行列と行列演算

講義資料 §5-1, §5-2。行列は、数を長方形に並べたものです。計算の順序に注意します。

用語説明

用語意味
m x n 行列横に n 個、縦に m 個の成分を持つ行列。
行・列横の並びが行、縦の並びが列。
零行列すべての成分が0の行列。
単位行列対角成分が1、その他が0の正方行列。記号は I または E。
転置行列行と列を入れ替えた行列。記号は A^T。右上の T は transpose の略で「転置する」という意味。
重要: 行列の積は順序が大切
一般に AB != BA。そもそも片方しか定義できない場合もあります。
最重要: 行列積のサイズ
(m x n)(n x p) = m x p。内側のサイズが一致するときだけ掛けられます。

行列積の見方

A: m x n, B: n x p AB の (i, j) 成分 = A の i 行 と B の j 列 の内積

「左の行」と「右の列」を合わせる、と覚えると計算ミスが減ります。

図解

行列積は順序で変わる

次の2つの行列で計算します。

A = 1101 , B = 1011
AB = 2111 , BA = 1112

数では 2 x 3 = 3 x 2 ですが、行列は「操作」なので順序が意味を持ちます。先に横へずらすか、先に傾けるかで結果が変わる、という感覚です。

積が定義できるか

A が 2 x 3、B が 3 x 4 なら AB は計算できます。

結果のサイズは 2 x 4。外側の数字が残り、内側の 3 は「足し合わせで消える」と見ると覚えやすいです。

行列積がこの形になる理由

行列 A は「入力ベクトルを別のベクトルへ変える操作」と見られます。ABx は、まず B で x を動かし、その結果を A でさらに動かす、という2段階の操作です。

だから AB と BA は一般に同じではありません。操作の順番が違うからです。

狙われやすい点

  • AB は計算できるが BA は計算できない、というサイズ問題。
  • AB = BA と勝手に入れ替えるミス。
  • 転置で (AB)^T = A^T B^T と書くミス。正しくは (AB)^T = B^T A^T。

6. ブロック分割

講義資料 §6-1。大きな行列を小さな行列のかたまりとして見る方法です。

用語説明

用語意味
ブロック行列行列をいくつかの長方形の小行列に分けたもの。
対角ブロック正方行列の対角線上に置かれたブロック。
ブロック積ブロックのサイズが合えば、普通の行列積と同じ形で計算できる。

扱い方

ブロック分割は、計算を楽にするための見方です。分割線を入れたあと、各ブロックを1つの成分のように扱います。

[ A B ] [ E F ] = [ AE + BG AF + BH ] [ C D ] [ G H ] [ CE + DG CF + DH ]

直感

表計算ソフトで範囲をまとめて扱う感覚に近いです。個々の数字ではなく、まとまり同士の関係を見ると構造が見えます。

7. 正則行列・逆行列

講義資料 §7-1。行列にも「逆数」にあたるものがあります。ただし正方行列に限られます。

用語説明

用語意味
正則行列逆行列を持つ正方行列。
逆行列A A^-1 = A^-1 A = I を満たす行列。
特異行列逆行列を持たない正方行列。
重要: 積の逆行列
(AB)^-1 = B^-1 A^-1。順序が逆になるのがポイントです。
最重要: 逆行列は方程式を解く道具
Ax = b で A が正則なら x = A^-1 b と一意に解けます。

直感

行列 A は空間を変形する操作です。逆行列 A^-1 は、その変形を元に戻す操作です。押しつぶして面積を0にするような操作は、元に戻せないので逆行列がありません。

逆行列がある例

次の A は、x方向を2倍、y方向を3倍する行列です。

A = 2003
A^-1 = 1/2001/3

2倍したものは1/2倍で戻せます。3倍したものは1/3倍で戻せます。だから逆行列があります。

逆行列がない例

次の B は2列目が1列目の2倍です。

B = 1224
det(B) = 1・4 - 2・2 = 0
列ベクトル (1, 2) と (2, 4) は同じ直線上にあります。

平面全体の情報が1本の方向に潰れます。潰れた後から元の位置を一意に復元できないので、逆行列はありません。

逆行列で狙われる判断

  • 正方行列でなければ逆行列は定義されない。
  • det(A) = 0 なら逆行列はない。
  • 掃き出しで左側を単位行列にできれば、右側が逆行列になる。
  • (AB)^-1 は順序が逆になり、B^-1 A^-1。

8. 基本変形・階数

講義資料 §8-1。行列計算の中核です。連立一次方程式、逆行列、階数がここでつながります。

用語説明

用語意味
行基本変形行の入れ替え、行の定数倍、別の行の定数倍を足す操作。
行階段形主成分が右下へ階段状に並び、下に零行が集まった形。
主成分・ピボット各行で最初に現れる0でない成分。
階数 rank行階段形にしたときの0でない行の本数。独立な情報の数。rank は「順位・階級」という英語で、ここでは情報の多さを表す記号。
最重要: 掃き出し法
左から順にピボットを作り、下を0にし、必要なら上も0にして標準形へ近づける。
最重要: 階数
階数は、連立方程式の解の有無・自由変数の数・逆行列の有無を判断する鍵です。

行基本変形の3種類

操作記号例意味
行を入れ替えるRi <-> Rj方程式の順番を変えるだけ。
行を0でない数倍するRi -> c Ri同じ方程式を定数倍する。
別の行を足すRi -> Ri + c Rj一方の方程式を使って消去する。

図解: 階段形

計算で迷ったとき

左端の0でない列を探す。
ピボットを上に持ってくる。必要なら行を入れ替える。
ピボットを1にする。
同じ列の下を0にする。
次の行・次の列へ進む。

階数が1になる例

2行目が1行目の2倍なら、情報は1行分しかありません。

1252410
R2 -> R2 - 2R1
125000

0でない行が1本だけなので rank は1です。行が2本あることではなく、独立な情報が何本あるかを数えます。

階数が2になる例

2行目が1行目の倍数ではない場合、2本分の情報があります。

1252512
R2 -> R2 - 2R1
125012

ピボットが2つ残るので rank は2です。連立方程式なら、2つの独立な条件があるという意味になります。

階数が「独立な情報の数」になる理由

行基本変形は、方程式の情報を失わずに見やすい形へ変える操作です。階段形にしたとき、0でない行はそれぞれ新しい条件を1つ表します。

零行は「新しい条件を何も追加していない行」です。だから、0でない行の本数を数えると、独立な条件の数が分かります。

狙われやすい点

  • 行基本変形後の行列から rank を読む。
  • rank が列数と等しいかどうかで自由変数の有無を判断する。
  • 正方行列で rank がサイズに等しいなら逆行列がある、と判断する。

9. 基本行列

講義資料 §9-1。行基本変形を「左から行列を掛ける操作」として表す章です。

用語説明

用語意味
基本行列単位行列に1回だけ行基本変形を施した行列。
左から掛けるP A とすると、A の行に操作がかかる。
右から掛けるA P とすると、A の列に操作がかかる。
重要: 基本変形と行列積の対応
行基本変形は、基本行列を左から掛けることと同じです。
補足: 正則性との関係
基本行列はすべて正則です。基本変形で単位行列にできる行列は正則です。

直感

行基本変形は手作業の操作に見えますが、実は「別の行列を掛けている」だけです。この視点が、逆行列の計算や階数の理論につながります。

10. 行基本変形による逆行列の計算

講義資料 §10-1。拡大行列 [A | I] を使って逆行列を求めます。

用語説明

用語意味
拡大行列2つの行列を横に並べたもの。逆行列計算では [A | I]。
掃き出し行基本変形で左側を単位行列に近づけること。
正則判定左側を単位行列にできれば正則。できなければ逆行列なし。
最重要: 計算手順
[A | I] -> [I | A^-1] を目指す。左側に行った操作が、そのまま右側にもかかる。

手順

[A | I] を作る。
行基本変形で左側の A を I にする。
右側に残った行列を読む。
左側に零行や矛盾が出て I にできなければ、逆行列なし。

図解

2×2で逆行列を作る

次の A の逆行列を、左を単位行列にする操作で求めます。

A = 1237
[A | I] = 12|1037|01
R2 -> R2 - 3R1
12|1001|-31
R1 -> R1 - 2R2
10|7-201|-31
A^-1 = 7-2-31

左側に行った操作を右側にも同時に行うから、右側には「AをIに戻す操作」が残ります。これが逆行列です。

なぜ右側が逆行列になるのか

行基本変形は、左から基本行列を掛けることと同じです。左側の A を I にできたなら、何らかの行列 P によって PA = I になったということです。

同じ P は右側の I にも掛かるので、右側は PI = P になります。しかも PA = I なので、この P が A^-1 です。

掃き出しで多いミス

  • 左側だけ操作して、右側に同じ操作をし忘れる。
  • 行を定数倍するとき、右側の全成分も同じ定数倍し忘れる。
  • 途中で列基本変形を混ぜてしまう。逆行列計算では行基本変形で統一します。

11. 連立一次方程式の解法

講義資料 §11-1。行列を使うと、連立方程式を統一的に解けます。

用語説明

用語意味
係数行列未知数の係数だけを並べた行列 A。
拡大係数行列右辺も含めて並べた [A | b]。
自由変数値を自由に選べる未知数。
一般解自由変数を含めて、解を全部表したもの。
最重要: 拡大係数行列を階段形にする
方程式を直接いじる代わりに [A | b] を行基本変形します。
最重要: 解の判定
rank(A) = rank([A|b]) なら解あり。違えば解なし。

解の数の判定

条件結論
rank(A) != rank([A|b])解なし
rank(A) = rank([A|b]) = n解はただ1つ
rank(A) = rank([A|b]) < n無数に解がある

図解: 2本の直線

一意に解ける例

次の連立方程式を考えます。

x + y = 5 x - y = 1 足すと 2x = 6 なので x = 3 y = 2

2本の直線が1点で交わるので、解は1つです。行列で見るとピボットが未知数2個ぶんあります。

解がない例

x + y = 1 x + y = 3

左辺は同じなのに右辺だけ違います。これは同時には成り立ちません。

掃き出しをすると 0 = 2 のような矛盾が出ます。これが rank(A) != rank([A|b]) の中身です。

rank 判定の意味

rank(A) は左辺の条件が持っている独立な情報の数です。rank([A|b]) は右辺まで含めたときの独立な情報の数です。

右辺を付け足した途端に rank が増えるなら、左辺だけでは説明できない条件が右辺に入ったことになります。これが「矛盾」、つまり解なしです。

連立方程式で多いミス

  • 自由変数を置いたあと、元の未知数に戻して一般解を書かない。
  • 0 = 0 の行を矛盾だと思ってしまう。これは条件が消えただけです。
  • 0 = 3 のような行を見落とす。これは即、解なしです。

12. 連立一次方程式の解の構造

講義資料 §12-1。同次方程式と非同次方程式の関係を押さえると、一般解が見やすくなります。

用語説明

用語意味
同次方程式Ax = 0。
非同次方程式Ax = b で、右辺が0とは限らないもの。
特殊解Ax = b の解を1つだけ選んだもの。
解空間Ax = 0 の解全体。これは部分空間になる。
最重要: 一般解の形
非同次方程式の解全体は、特殊解 + 同次方程式の一般解 で表せます。
重要: 自由度
Ax = 0 の解空間の次元は n - rank(A) です。

直感

Ax = 0 の解は「動いても右辺を変えない方向」です。非同次方程式 Ax = b の解は、1つの解からその方向へ動かしたもの全部になります。

特殊解 + 同次解を実感する

x + y = 4 の解を全部表します。

特殊解の1つ: (4, 0) 同次方程式 x + y = 0 の解: t(1, -1) よって一般解: (x, y) = (4, 0) + t(1, -1) = (4 + t, -t)

まず1つだけ解を見つける。その後、「右辺を変えずに動ける方向」を全部足す。この2段階で一般解を作ります。

13. 行列式

講義資料 §13-1, §13-2。講義範囲では2次・3次の行列式と幾何学的意味が中心です。

用語説明

用語意味
行列式正方行列に対して定まる数。記号は det(A) または |A|。
符号行列式では、項にプラス・マイナスが付く。置換の偶奇と関係する。
面積倍率・体積倍率行列が図形を何倍の面積・体積に変えるかを表す。
重要: 2次行列式
2×2行列の成分を左上から a, b, c, d と置くと、det(A) = ad - bc。
重要: 3次行列式
展開式またはサラスの方法で計算します。符号の付け忘れに注意。
補足: 幾何学的意味
絶対値は面積・体積の倍率、符号は向きが保たれるか反転するかを表します。

公式

2 x 2: | a b | | c d | = ad - bc 3 x 3: | a11 a12 a13 | | a21 a22 a23 | | a31 a32 a33 | = a11 a22 a33 + a12 a23 a31 + a13 a21 a32 - a13 a22 a31 - a12 a21 a33 - a11 a23 a32

図解: 面積倍率

2次行列式の計算

A = 2134
det(A) = 2・4 - 1・3 = 5

det(A) = 5 は、この行列が面積を5倍にするという意味です。0でないので、逆行列もあります。

行列式が0になる計算

B = 1224
det(B) = 1・4 - 2・2 = 0

2列目が1列目の2倍なので、平行四辺形の面積が0になります。公式だけでなく「2本が同じ方向に潰れている」と見るのが本質です。

2次行列式の公式の背景

2本の列ベクトル (a, c), (b, d) が作る平行四辺形の符号付き面積が ad - bc です。

ad は「まっすぐ広がる面積」、bc は「斜めに重なって余分に数えた面積」を差し引く部分だと見ると、公式がただの暗記ではなくなります。

狙われやすい点

  • ad + bc と足してしまうミス。2次行列式は必ず ad - bc。
  • 行列式が0なら、列ベクトルが一次従属であることを説明させる問題。
  • 行列式が0でないなら、逆行列が存在することを判断させる問題。

つまずきやすい点

det(A) = 0 は、列ベクトルが作る面積・体積が0になるという意味です。つまり、ベクトルが同じ直線や同じ平面に潰れていて、独立な広がりを作れていません。このとき行列は正則ではありません。

13.5 レポート・復習型の重要問題

レポート課題と復習問題で扱われている型から、期末試験でも狙われやすいものを選び、次に自分で解けるように手順化します。

レポート1型: 部分空間判定

連立同次条件で定まる集合が部分空間か判定する

次の集合を考えます。

W = { xyz in R^3 | 2x + 3y - z = 0, x - 2y + 3z = 0 }
零ベクトルを代入する。どちらの式も0になるので、零ベクトルは入る。
2つの解 u, v を足す。式は線形なので、左辺もそれぞれ足され、0 + 0 = 0 になる。
解 u を c 倍する。左辺も c 倍され、c・0 = 0 になる。
よって和とスカラー倍で閉じているので、W は部分空間。

同じ形でも右辺が0でないと危ない

2x + 3y - z = 1 のように右辺が0でない条件では、零ベクトルが入らないので部分空間ではありません。レポート1でもこの違いが問われています。

復習1型: 基底判定

3本のベクトルが R^3 の基底か判定する

次の3本が基底かを判定します。

v1 =101 v2 =011 v3 =100
c1v1 + c2v2 + c3v3 = 0 と置く。
成分ごとに見ると、c1 + c3 = 0, c2 = 0, c1 + c2 = 0。
c2 = 0 かつ c1 + c2 = 0 より c1 = 0。さらに c1 + c3 = 0 より c3 = 0。
全部0しかないので一次独立。R^3 の3本の一次独立なベクトルだから基底。

基底判定は「一次独立」と「生成」の両方が必要ですが、R^3 で3本ある場合は、一次独立を示せば自動的に生成も分かります。

レポート3型: 冪零行列と二項定理

(I + A)^10 を短く計算する

行列 A が A^3 = O を満たすとき、(I + A)^10 は全部展開する必要がありません。

普通の二項定理の形を思い出す。(1 + x)^10 = 1 + 10x + 45x^2 + ...。
行列でも I と A は可換なので、同じ形で展開できる。
A^3 = O なら、A^3, A^4, ... は全部0。
したがって (I + A)^10 = I + 10A + 45A^2。

テストでの狙われ方

巨大なべき乗をまともに10回掛ける問題ではありません。「冪零だから途中で消える」と気づけるかが狙いです。

復習2型: AB = BA となる行列

可換条件を成分比較で求める

2次正方行列 A に対して、AB = BA となる B を求める型です。

A = 1201 , B = abcd
まず B を未知数入りの一般形で置く。
AB と BA をそれぞれ計算する。
対応する成分を比較して、c = 0, a = d のような条件を得る。
条件を B に戻して、答えを行列の形で書く。
答えの形: B = ab0a (a, b は任意)

ポイントは、AB = BA を「行列全体が等しい」と見るのではなく、「対応する成分がすべて等しい」と分解することです。

レポート4型: 行基本変形と階数

行列を行基本変形して rank を読む

レポート4では、行基本変形で簡単な形に直し、rank や正則行列 P を求める型が扱われています。

行基本変形の目標: 1***01**001*
ピボットが3つあれば rank は3です。
左上からピボットを作る。必要なら行を入れ替える。
ピボットの下を0にする。計算の目的は「見やすい階段」を作ること。
0でない行の数を数える。これが rank。
行基本変形を記録すると、それらをまとめた行列が P になり、PA = B と表せる。
復習4型: パラメータ付き連立方程式

解が存在するための条件を求める

パラメータ a, b を含む連立方程式では、掃き出し後に出る矛盾行を見ます。

掃き出し後に 10**| a01**| b0000| -3a0000| -4a+b-2
零行の右辺に注目する。左辺が全部0なら、右辺も0でないといけない。
-3a = 0 より a = 0。
-4a + b - 2 = 0 に a = 0 を入れて、b = 2。
したがって解が存在する条件は a = 0, b = 2。

このタイプは、最後まで未知数を解くことよりも「矛盾が出ない条件」を読むことが本質です。

復習5型: 置換の符号

置換を互換の積で表し、符号を求める

例えば、上段を 1,2,3,4,5、下段を 5,4,2,1,3 とする置換を考えます。

置換は「数字の並べ替え」です。互換は2つの数字だけを入れ替える操作です。
互換の個数が偶数なら符号は +1、奇数なら -1。
レポートの解答例では偶数個の互換で表せるため、sgn(σ) = 1。

符号で多い勘違い

互換の分解方法は1通りではありません。しかし、互換の個数が偶数か奇数かは変わりません。だから符号は一意に決まります。

14. 勉強の進め方

復習・レポート解答例は、定義の確認よりも「計算手順の定着」に使うのが効果的です。

優先順

  1. 部分空間、一次独立、基底、次元の定義を言えるようにする。
  2. 行基本変形を、途中式を省略せずに書けるようにする。
  3. 階数から、逆行列の有無と連立方程式の解の数を判断する。
  4. 2次・3次の行列式を符号まで正確に計算する。
  5. 行列式の意味、解空間の意味を図で説明できるようにする。

演習テーマの対応

演習で確認したいこと見る章

このサイトの使い方

まず目次から苦手な章へ飛び、「用語説明」だけを読んでから重要度欄を確認してください。そのあと図解と手順を見て、最後に講義資料・復習問題で同じ型を解くと定着しやすいです。

読むだけで終わらせないための問い

  1. その概念は「何を判定するため」にあるのか。
  2. 最小の例、つまり R^2 や 2 x 2 で試すとどうなるか。
  3. うまくいく例だけでなく、失敗する例は何か。
  4. 公式の各記号は、具体例ではどの数字に対応するか。
  5. 答えを出したあと、その答えが意味として自然かを図で説明できるか。
