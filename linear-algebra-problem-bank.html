レポート1

部分空間の判定

最初に見るのは、条件の右辺が0かどうかです。

問1(1) 2本の同次方程式を満たす集合は部分空間か
W = {xyz∈ R³ | 2x+3y−z=0, x−2y+3z=0 }

解答の組み立て

零ベクトルを代入すると両式の左辺は0。したがって 0∈W。
u,v∈W とする。各式は成分の一次式なので、u+v の左辺は「uの左辺＋vの左辺」すなわち0になる。
c∈R とすると、cu の左辺は元の左辺のc倍で c·0=0。
零ベクトル、加法、スカラー倍の3条件を満たすため、Wは部分空間。
本質

これは行列Aを使えば W={x | Ax=0}、つまり線形写像の核です。核は必ず部分空間になります。

問1(2) 右辺が0でない連立条件ではどうなるか
W = {xyz∈ R³ | 2x+3y−z=1, x−2y+3z=2 }
部分空間なら零ベクトルを必ず含む。
x=y=z=0 を代入すると左辺は0で、右辺1, 2と一致しない。
よって 0∉W なので、Wは部分空間ではない。
よくある誤り

「一次方程式で定まる集合は部分空間」と丸暗記しないこと。同次方程式 Ax=0 の解集合は部分空間ですが、Ax=b (b≠0) は原点を通らない平行移動された集合です。

演習1

部分空間、基底と次元

反例を作る力と、自由変数から基底を読む力をまとめて鍛えます。

問1(1)〜(6) R³の部分集合を判定する

(1) 同次連立方程式

x₁+x₂+x₃=0, 2x₁−3x₂+x₃=0。部分空間。同次連立方程式の解集合、すなわち線形写像の核だからです。

(2) 非同次連立方程式

x₁−3x₂+2x₃=1, x₁−x₂+4x₃=0。零ベクトルが第1式を満たさないため、部分空間ではない。

(3) 不等式で定まる集合

x₁+2x₂−3x₃≤2, x₁+x₂+x₃≤2。(1,0,0)ᵀ,(2,0,0)ᵀ は入りますが、和 (3,0,0)ᵀ は入りません。加法で閉じないので部分空間ではない。

(4) 2次式の条件

x₁²−2x₂²+x₃²=0。(1,1,1)ᵀ,(1,−1,1)ᵀ は入る一方、和 (2,0,2)ᵀ は入りません。よって部分空間ではない。

(5) 平方を整理できる条件

x₂²+x₃²=2x₂x₃ は (x₂−x₃)²=0、実数上では x₂=x₃ と同値です。これは原点を通る平面なので部分空間。

(6) 2平面の和集合

x₁²=x₃² は x₁=x₃ または x₁=−x₃。(1,0,1)ᵀ,(1,0,−1)ᵀ は入りますが、和 (2,0,0)ᵀ は入らないため部分空間ではない。

反例の作り方

「または」で複数の直線・平面が合体している集合では、別々の枝から1点ずつ選んで足すと、集合から外れる反例を作りやすいです。

問2(1)〜(3) 多項式空間の部分集合を判定する

ここで R[x]₃ は「次数が3以下の実係数多項式全体」です。

(1) f(−1)=1, f(3)=0

零多項式は f(−1)=1 を満たさないため部分空間ではない。

(2) f(1)≤0, f(2)=0

f=−2−x−x²+x³ は条件を満たしますが、−f は (−f)(1)=3>0。−1倍で閉じないため部分空間ではない。

(3) f″(x)−2xf′(x)=0

作用素 T(f)=f″−2xf′ は線形で、集合は核 ker T。したがって部分空間です。さらに f=a₀+a₁x+a₂x²+a₃x³ を代入するとa₁=a₂=a₃=0となり、この空間は定数多項式全体です。

問3(1) 連立方程式で定まるWの基底と次元
係数行列→10102010000001−1
主変数は x₁,x₂,x₄、自由変数は x₃,x₅。x₃=c₁,x₅=c₂ と置く。
x₁=−c₁−2c₂, x₂=0, x₄=c₂。

自由変数を x₂=c₁,x₄=c₂,x₅=c₃ と選ぶ。
掃き出し結果から x₁=2c₁−3c₂−c₃, x₃=c₂−2c₃。

問4 積分条件で定まる多項式空間

W={f∈R[x]₃ | ∫₋₁¹ f(x)dx=0}

積分は線形なので、零多項式、和、スカラー倍の3条件が保たれ、Wは部分空間。
f=a₀+a₁x+a₂x²+a₃x³ と置く。奇関数のx,x³は対称区間で積分0。
条件は 2a₀+(2/3)a₂=0、したがって a₀=−a₂/3。
f=a₁x+a₂(x²−1/3)+a₃x³。基底は {x, x²−1/3, x³}、dim W=3。
問5 W₁+…+Wₖ が部分空間であることを示す
各Wᵢは部分空間なので0を含む。0=0+…+0 より和空間も0を含む。
x=x₁+…+xₖ, y=y₁+…+yₖ と表すと、x+y=(x₁+y₁)+…+(xₖ+yₖ)。各括弧はWᵢに入る。
cx=cx₁+…+cxₖ も各項がWᵢに入る。
3条件を満たすので W₁+…+Wₖは部分空間。
証明の型

和空間の元を「各部分空間から1つずつ選んだ和」と書き戻すことが中心です。

問6 V+W の基底と次元

Vは v₁=(1,0,2,2)ᵀ, v₂=(0,1,0,1)ᵀ、Wは w₁=(1,−1,1,1)ᵀ, w₂=(1,−1,2,1)ᵀ で生成される。

4本を列に並べた行列 [v₁ v₂ w₁ w₂] を行基本変形する。
主列に対応する元の列は第1、第2、第3列。
したがって基底は {v₁,v₂,w₁}、dim(V+W)=3。
重要

基底に採用するのは、変形後の列ではなく「主列と同じ番号の変形前の列」です。行基本変形は列同士の一次関係を保ちますが、列そのものは変わります。

途中で [0 0 0 0 | 1]、つまり方程式 0=1 が現れる。
これは矛盾なので 解なし。
判定の言葉

「計算できない」ではなく、「係数行列の階数と拡大係数行列の階数が異なるため解なし」とも説明できます。

検算済み

4次の答えは左から元のAを掛けてE₄になることを確認しています。掃き出しでは行操作を左右のブロックへ同時に適用してください。

問4 ブロック行列のk乗を帰納法で示す
M=EₘAOEₙのとき Mᵏ を求める
k=1 では、求める形はもとのMそのもの。
あるkで
Mᵏ=EₘkAOEₙ
と仮定する。
Mを右から掛けると右上ブロックは EₘA+kAEₙ=(k+1)A。
よって
Mᵏ=EₘkAOEₙ
直感

右上のAだけが掛けるたびに1個ずつ加算されます。対角が単位行列なので、Aの向きや大きさは変わりません。

問5 2A²+3A−7E=O から逆行列を作る
式を 2A²+3A=7E と移項する。
左辺からAをくくり A(2A+3E)=7E。逆順も同じ多項式なので (2A+3E)A=7E。
7で割れば
A⁻¹=(1/7)(2A+3E)
証明の完成条件

「候補を得た」だけではなく、左右どちらから掛けてもEになることを示します。Aの多項式同士なので可換することも理由になります。

問6 A⁴=O のとき E+A の逆行列
交代符号の和 B=E−A+A²−A³ を作る。
(E+A)B=E−A⁴=E。逆順でもE。
(E+A)⁻¹=E−A+A²−A³
レポート3との接続

レポート3のA⁶版と全く同じ原理です。指数nに対してAⁿ⁻¹まで書き、最後にAⁿが消えます。
